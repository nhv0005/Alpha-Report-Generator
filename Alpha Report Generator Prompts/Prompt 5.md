### 10. src/app/api/* (Route Handlers)
Next.js API route handlers that proxy to the Python backend:

**src/app/api/alpha/generate/route.ts**
```typescript
export async function POST(request: Request) {
  const body = await request.json();
  const response = await fetch(`${PYTHON_SERVICE_URL}/api/alpha/generate`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      // Forward traceparent/tracestate for W3C propagation
      ...extractTraceHeaders(request.headers),
    },
    body: JSON.stringify(body),
  });
  return Response.json(await response.json());
}
```

### Key Requirements

The app must NOT have any OpenTelemetry or OpenInference SDK
It relies ENTIRELY on Dynatrace OneAgent for instrumentation
W3C Trace Context headers must flow through API route handlers to Python
All pages must handle loading, error, and empty states gracefully
The report viewer must render Markdown content beautifully
The generation progress tracker must feel responsive (2s polling)
Dark theme throughout — professional, finance-industry aesthetic
Responsive design (works on desktop and tablet)
No external API calls for financial data — all data comes from Python backend
TypeScript strict mode
